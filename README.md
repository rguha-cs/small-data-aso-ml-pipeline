# Biophysics-Informed Family-Aware Machine Learning Enables Cross-Target Prediction of RNase H-Active Antisense Oligonucleotide Efficacy

This repository accompanies the Frontiers in Systems Biology manuscript of the same title. It contains all code, curated datasets, cached feature representations, and analysis notebooks required to reproduce the computational analyses, manuscript figures, and supplementary tables presented in the publication.

Authors: Risha Guha et al.

# Python Environment

The notebooks were developed under **Python 3.10** (Python 3.10.18 recommended).

Create a virtual environment and install the required Python packages:

```bash
python -m venv .venv

# Linux / macOS
source .venv/bin/activate

# Windows PowerShell
.venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
pip install -r requirements.txt
```

Launch Jupyter:

```bash
jupyter lab
```

# External Dependency: ViennaRNA

Some feature-generation functions in `src/` can recompute RNA thermodynamic and accessibility features directly from sequence.

The manuscript feature calculations used **ViennaRNA v2.4.7**, specifically:

- `RNAduplex`
- `RNAplfold`

ViennaRNA is a **system dependency** and is **not installed through `requirements.txt`**.

Verify that the executables are available on your system PATH:

```bash
RNAduplex --version
RNAplfold --version
```

For reproducing the published manuscript analyses, installation of ViennaRNA is **not required** because the repository includes the cached feature matrices used during model development.

ViennaRNA is only required if you wish to regenerate the thermodynamic or RNA-accessibility features directly from sequence.

# Workflow

Execute the notebooks in the following order.

## Notebook 01 — Model Training and Validation

This notebook:

- prepares the curated literature dataset
- loads or regenerates cached feature representations
- trains the final Gradient Boosting Regression (GBR) model
- performs internal validation
- evaluates the model on independent wet-lab ASOs
- exports prediction and feature artifacts required by downstream notebooks

Outputs:

- trained model artifacts
- prediction files
- cached feature matrices
- validation metrics
- Figure 4 feature-ablation summary

---

## Notebook 02 — Generation of Main Manuscript Figures

This notebook reproduces the primary manuscript figures directly from the outputs generated by Notebook 01.

Outputs:

- Figure 4
- Figures 5–8
- Supplementary Figure S7
- Supplementary Table S5

No model training is performed in this notebook.

---

## Notebook 03 — Leave-One-Family-Out Calibration Validation

This notebook evaluates the proposed one-shot family calibration strategy using leave-one-family-out (LOFO) validation.

Outputs:

- LOFO calibration summary
- repeat-level calibration results
- Supplementary Figure S8
- Supplementary Table S8

# Reproducibility

To support exact reproduction of the published analyses, the repository includes:

- curated literature-derived datasets
- independent wet-lab validation datasets
- cached feature matrices
- intermediate feature snapshots
- fixed random seeds used throughout model training and evaluation

The supplied cached feature matrices are recommended for reproducing the reported results because thermodynamic calculations can vary slightly across external software versions.
